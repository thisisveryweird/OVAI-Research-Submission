## 1. What the frozen five names establish—and do not
`run_phase6_feature_selection.py::select_features` lines 199–223 fits median imputer/scaler and sparse selector on outer-training rows, then ranks absolute coefficients with stable sorting. `evaluate_task` 244–300 uses the same five splits for two methods × six sizes; `stability_frame` 331–351 counts selections/5. Zero-coefficient ties can fill requested sizes in original column order; high frequency is not necessarily nonzero-effect evidence. Phase 6 uses raw TPM, saga selectors. Phase 7 `select_top_mirnas` 160–184 uses log1p clipped TPM, liblinear L1; therefore these are not identical discovery procedures.

The saved Phase 6 early-stage L1 Top-5 counts for frozen names are: miR-296-3p 5/5, miR-1255a 4/5, miR-200b-3p 4/5, miR-32-3p 3/5, miR-6826-5p 1/5. miR-200a-3p also has 3/5: the frozen set is not simply this table's top five. Phase 7 early-stage counts are miR-200b-3p 5/5, miR-296-3p 5/5, miR-6826-5p 4/5, miR-1255a 3/5, miR-32-3p 1/5; let-7a-2-3p has 2/5 and other names tie at 1/5. `main` 391–433 computes fold selections once and reuses them across all ablations, models and imputations; repeated stability lines, including clinical-only configurations, are not independent replications.

These five names exactly match literal SIGNATURE lists in `test_high_capacity_models.py` 31–38, pairwise 44–51 and rank 45–52. The matching names/counts are proven from source plus saved report text. None of these scripts reads stability output to deterministically freeze this list, records an owner decision, discovery cohort lock/date, or untouched split. Human choice, chronology and all prior label exposure remain unknowable here. AUC progression is not proof of causal leakage. PDF pp15–16 raises a plausible same-cohort discovery concern, correctly conditional; its blanket claim that each CV is implemented correctly is too strong. PDF pp6,15 calls the frozen logistic result nested: its logistic branch has no inner search or nested discovery. It is conditional fixed-panel outer CV, not unbiased evaluation of the complete discovery process.

## 2. Outer safety is not strict inner containment
- Phase 6 `evaluate_task` 244–300: selection/preprocessing/classifier fit outer-training only; fixed settings, no inner optimization. `result_frame` 303–328 averages fold metrics and computes sample SD for AUC. Choosing a method/size after seeing these results adds experiment-level selection not accounted for by that CV.
- Phase 7 `impute_clinical` 123–157 and `evaluate_configuration` 227–299: median/KNN imputation, scaling and supervised molecular selection are outer-contained. KNN operates on unscaled age/CA125 and is a sensitivity analysis, not measured clinical values. `fit_model` 187–211 calibrates only LinearSVC (cv=3); selection, imputation and scaling have already seen calibration-held-out rows inside the outer training set. No outer-held-out leakage demonstrated, but strictly fold-contained calibration is not achieved.
- Phase 8 `main` 275–338, especially 287–288: `selected = select_top_features(...)` and `transform_fold(...)` precede `fit_tuned_model` 181–195. Inner GridSearchCV sees arrays already selected using all outer-training labels and imputed/scaled using all outer-training statistics. This contaminates inner validation. `inner_oof_base_predictions` 212–226 retunes base estimators on each inner training subset, yet receives those same preselected/preprocessed arrays. Meta probabilities are estimator-OOF, not whole-procedure strictly OOF. SVM calibration similarly wraps only the estimator (141–178). Outer test rows remain excluded from these fits; the issue is inner objective/meta-training/calibration validity, not evidence that outer test labels were directly fit.
- Phase 9 `prepare_fold` 119–143 and `apply_augmentation` 146–172: sampler receives transformed training only, never validation. Same folds/transforms for all nine arms (`main` 297–366); duplicate selector call at 313–314 is redundant but deterministic. No inner tuning here. If augmentation/model is later selected, that selection requires inner containment. `write_report` 263–291 selects largest observed sensitivity delta post hoc and applies an unprespecified-in-study 5-point specificity tolerance; not confirmatory evidence. BorderlineSMOTE's assertion of exact balancing can abort when no suitable danger samples exist; a log assertion is not a runtime audit trail.

PDF p8 requests fold-local discovery/global-filter repair and calibration/DCA; pp16–17 recommends interaction-space discovery or untouched validation. Those proposals need the stricter design in PATCH_SCOPE.md, not just adding another outer-fold loop. PDF pp21,23 probability/operating-point proposals require validation; Brier values or sigmoid calibration constructors alone do not establish calibrated clinical risk.

## 3. Interactions: fixed hypothesis, paired folds, incompatible missingness
`test_high_capacity_models.py::load_training_data` 56–71 logs five miRNAs before fitting; fallback can derive clinical rows from error-analysis output, then deduplicates without reconciling per-model copies (`validate_endpoint` 42–53). `engineered_frame` 93–97 contains exactly two predetermined products: log1p(miR-200b-3p)×CA125 and log1p(miR-296-3p)×age. Neither interaction partners nor five-name panel is selected inside CV. `run` 117–143 compares no-interaction/interaction on identical folds and pools all OOF probabilities before scoring. SVM GridSearchCV includes imputer/scaler in the searched pipeline (100–114): those statistics are inner-contained, unlike Phase 8, but frozen-panel provenance remains unresolved.

Products are formed BEFORE `base_pipeline` 85–90 median imputation. Thus a missing age/CA125 causes product missingness, which is filled by training median of the observed products. The sibling inference audit reports deployment/export impute bases BEFORE multiplication. In general median(a×b) ≠ a×median(b); a patient-dependent product cannot be replaced by a cohort median product and assumed equivalent. This is a train/evaluate/deploy transform mismatch, not merely a naming issue. Product operation itself is row-local, so constructing validation products is not a fit leak; data-derived product imputation is fold-local. A remediation must specify one order and test exact parity, including both missing and complete rows.

Saved high-capacity results: frozen AUC .8994 / BA .8657 / sensitivity .8462 / specificity .8852; engineered .8997 / .8643 / .8269 / .9016. ΔAUC +.0003, sensitivity −.0193, specificity +.0164. At the stated N these rounded values correspond to approximately one more FN and one fewer FP, not a proven clinically preferable model. The table label “Mean OOF ROC-AUC” is wrong for the source estimator: it computes one pooled OOF AUC. PDF pp6,17 repeats these tradeoffs but cannot authorize choosing a deployment model or establish utility.

## 4. Metric denominators and analysis limitations
Saved Phase 6 early L1 five AUC .749; Phase 7 combined median logistic .827 (sensitivity .751, specificity .835); Phase 8 logistic .823 and stacked .825; Phase 9 unaugmented logistic .827, BorderlineSMOTE .825, SMOTE .821. These are arithmetic means across five folds, not pooled AUCs. Phase 9 displayed sensitivities do not improve for any arm at reported precision. Phase 8/9 `pr_auc` is sklearn average precision, not trapezoidal PR integration. AUC comparisons with high-capacity pooled .8994/.8997 mix aggregation as well as transforms, panel choice, clinical inclusion and endpoints; the difference cannot be attributed solely to discovery leakage or patient difficulty. Phase 7 does not save the fold_table it constructs (main 435–446), despite printing its count. Phase 8/9 save patient probabilities, making pooled calculations possible in a separately authorized audit; none were recomputed here.

`analyze_gse94533_errors.py::binary_metrics` 50–73 scores pooled subset probabilities at 0.5, while `main` 162–186 writes correctness/error types from saved prediction columns. If saved decisions used tuned thresholds, those are different classifications. Joins 116–141 preserve OOF row count but do not prove all metadata joined or agree with labels (metadata label dropped). Stage-I CSV row at 207 contains only Stage-I cancer and no controls; it cannot be two-class despite its name. Later narrative stage-I mask includes noncancer and differs. “three_class_ranking” still uses binary labels; later one-v-rest AUC uses the SAME cancer score for benign and borderline, not learned class-specific probabilities. Feature contrasts 93–113 rank descriptive standardized differences, not inferential tests or causal explanations. Histology counts among FNs need subtype denominators to quantify sensitivity. PDF p20's “not a data artifact” is unsupported by this static review; stage grouping and missingness are source/report claims requiring local data.

Rank `WithinPatientBackgroundRankTransformer` 65–120 computes row-local ranks; fit only checks columns. `local_cross_validation` 230–243 scores pooled OOF raw/rank predictions with fold-local pipeline medians/scales. External 188–227 ranks all available probe backgrounds and averages target-probe ranks, not necessarily the same hsa-miRNA background as local; annotation/probe multiplicity can affect comparability. Retention requires only ANY target observed, not all five. Cached-only loader uses imported metadata label rules not audited in this chunk; missing files escape `run`'s ValueError-only handler. Pairwise `pairwise_features` 55–69 is ten A>B indicators, not arithmetic ratios (ties are zero), rejects missing/non-numeric targets but not infinities. `cross_validate` 90–97 scores pooled probabilities; scaling is fold-local. Only first three external accessions are attempted (133–165). No external labels train these models in these sources; that does not establish cohorts were untouched by the broader research program. PDF p23's universal failed-corrections/biological-transfer narrative is not proven by reading implementation alone.
