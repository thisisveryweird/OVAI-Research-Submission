8:

10: 
11: - total subjects: 678
12: - cancer: 286
13: - controls: 392
14: - training subjects: 468
15: - independent internal validation subjects: 100
16: - independent external validation subjects: 110
17: - serum miRNA measurements: 180
18: - serum protein biomarkers: 7
19: - age: present
20: - menopausal status: present
21: 
22: ## Current status of the raw data
23: 
24: The individual-level supplementary Data File S1 is not present in this workspace, and the public publisher-facing metadata available from the DOI/article page does not provide the raw patient-level table. 25: 
26: A full audit requires the actual Data File S1 or equivalent patient-level supplementary table. Until that is retrieved and reviewed, this dataset remains a literature-level candidate rather than an usable external validation dataset for OVAI.

### reports\clinical_ablation_results.md
1: # Phase 7 Clinical Ablation Results
2: 
3: This study uses only the verified local GSE94533 cohort. HE4 is not present and is excluded from every pipeline. No external dataset is loaded.
4: 
5: ## Protocol
6: 
7: Each configuration uses shuffled stratified 5-fold cross-validation. Age is median-imputed inside each training fold. CA-125 is evaluated with either fold-local median imputation or fold-local KNN imputation. The Top-5 miRNA signature is selected by fold-local L1 logistic regression from the full local miRNA feature space; no global five-feature list is used.
8: 
9: Borderline tumors are included in the all-cancer versus non-cancer endpoint and excluded from the Stage I/II versus benign/control endpoint.

### reports\cptac_acquisition_audit.md
1: # CPTAC Ovarian Proteomics Acquisition Audit
2: 
3: Audit date: 2026-09-19
4: 
5: ## Decision
6: 
7: CPTAC ovarian mass-spectrometry data were **not downloaded into the diagnostic training set**. The requested use as "blood proteins alongside serum miRNA" is not supported by the available CPTAC ovarian resources: the public CPTAC client exposes ovarian tumor-proteomics sources, not a verified blood-protein cohort linked to GSE94533.
8: 
9: Downloading tumor proteomics and appending it to GSE94533 serum rows would create invalid patient-level multimodal records unless the same patients, specimen types, collection times, and endpoint labels were verified. It would also change the biological task from circulating cancer detection to tissue tumor characterization.
10: 
11: ## Verified Source Information
12: 
13: The public `cptac` client package (version 1.5.14 available from PyPI) defines ovarian (`ov`) sources including:
14: 
15: - BCM
16: - Broad
17: - MSSM
18: - UMich
19: - WashU
20: - Harmonized
21: 
22: These are CPTAC ovarian tumor-proteomics source families. No local CPTAC matrix, patient map, blood specimen table, or GSE94533 crosswalk is present in this repository.
23: 
24: The repository's existing compatibility matrix records CPTAC as conditional only. It has unknown local patient counts, unknown overlap with TCGA/GSE94533, and no verified compatible serum diagnostic endpoint.
25: 
26: ## Why No Download Was Performed
27: 
28: 1. The requested tissue/source is blood, but the identified CPTAC ovarian resources are tumor tissue proteomics.
29: 2. No patient-level linkage to GSE94533 has been established.
30: 3. No verified cancer-versus-benign/borderline/control phenotype aligned to GSE94533 is available locally.
31: 4. A downloaded tissue matrix would be useful for a separate tissue-proteomics or biological discovery analysis, not for the current serum diagnostic fusion model.
32: 5. The download may include multiple source releases and large files; selecting one without a manifest, access status, assay definition, and patient-level deduplication would reduce reproducibility.
33: 
34: ## Safe Next Step
35: 
36: A future CPTAC analysis should first select one named PDC/CPTAC release, save its project/file manifest and checksums, identify specimen type and assay workflow, normalize to one row per patient, audit repeated samples and overlap with TCGA/other CPTAC sources, and evaluate it as a separate tissue endpoint. It should not be merged with GSE94533 unless a validated patient/specimen mapping and compatible clinical endpoint exist.
37: 
38: ## Conclusion
39: 
40: CPTAC does not currently provide a scientifically valid way to add "blood proteins" to the GSE94533 serum-miRNA model. The requested accuracy improvement cannot be claimed from this source without changing the endpoint or fabricating multimodal patient rows.

### reports\current_pipeline_audit.md
1: # OVAI Current Pipeline Audit
2: 
3: Audit date: 2026-09-19
4: 
5: Scope: the 83 scripts under `scripts/`, committed data/model/report artifacts, top-level documentation, and the current metric-producing pipelines. No model code or data was changed for this audit.
6: 
7: ## Executive Findings
8: 
9: 1. The canonical GSE94533 diagnostic result is a patient-level, nested 5-fold OOF evaluation on 179 patients: 96 cancer and 83 non-cancer. The 14-miRNA plus age plus CA-125 logistic model produces 73.74% accuracy and ROC-AUC 0.8131. This is the most coherent current serum diagnostic benchmark, but it is internal resampling within one cohort, not an independent external test.
10: 2. The reported 76.54% accuracy and 77.06% balanced accuracy come from the calibrated-SVM branch of `evaluate_gse94533_enhancements.py`. Its threshold is selected separately inside each outer training fold, so the reported threshold-tuned OOF estimate is not an ordinary fixed-0.5 estimate. It is a valid nested research estimate, but it is still single-cohort OOF performance and should not be called external validation.
11: 3. GSE106817 is an independent serum cohort for ranking assessment, but its current frozen evaluation predicts every sample as non-cancer at the training-derived threshold: accuracy 89.70%, balanced accuracy 0.50, sensitivity 0%, specificity 100%. Its ROC-AUC 0.8232 is the informative result. The accuracy is a class-imbalance artifact and must not be reported as diagnostic success.
12: 4. The methylation result of 88.14% accuracy, 86.90% balanced accuracy, and 0.9414 ROC-AUC is nested OOF evaluation within the MethylBERT supplementary cohort, not an independent test of a model trained elsewhere. The early-stage comparison is 84.13% accuracy, 77.26% balanced accuracy, and 0.8609 ROC-AUC. These data are not patient-linked to GSE94533.
13: 5. The repository does not contain evidence that a claimed historical `>80%` independent-test result was reproduced. The exact historical PMML model is evaluated on all 179 historical patients, which is apparent historical performance. A separate script searches 20,000 compatible 44-patient splits near the published AUC and explicitly says a candidate is not proof of the original split. No committed output identifies the original 44 patients or a verified independent test metric. The current `>80%` numbers that can be traced exactly are the methylation within-cohort OOF accuracy and the invalid GSE106817 all-negative accuracy.
14: 6. There is no valid patient-level multimodal cancer-detection fusion model in the current committed results. GSE94533 miRNA plus clinical values are patient-linked. TCGA RNA/miRNA/clinical features are patient-linked but use a tumor-stage endpoint. Methylation and serum miRNA cohorts remain separate, as required by the repository's scientific rule.

### reports\gse106817_platform_shift_audit.md
1: # GSE106817 Platform-Shift Audit
2: 
3: This audit uses GSE94533 as the training cohort and keeps GSE106817 untouched. It does not fit a transform on external labels and does not add GSE106817 to training.
4: 
5: GSE106817 samples evaluated: 3108. Full title-derived groups: {'cancer': 320, 'benign': 29, 'borderline': 66, 'control': 2759, 'other': 872}.
6: 
7: ## What Normalization Can and Cannot Do
8: 
9: The existing external evaluation already fits standard scaling and a source-fitted quantile transform on GSE94533 only. This audit quantifies feature distribution differences and records those frozen results. These transforms can alter numeric scale; they cannot prove that GPL21263 measurements are assay-equivalent to the GSE94533 processed serum miRNA measurements, recover missing batch covariates, or make an external cohort part of the training pool.
10: 
11: ## Largest Distribution Differences
12: 
13: - `hsa-miR-29a-3p`: KS=1.000, median log1p shift=-5.458, source-fitted external median z=-6.934.
14: - `hsa-miR-92a-3p`: KS=1.000, median log1p shift=-7.421, source-fitted external median z=-10.024.
15: - `hsa-miR-1307-5p`: KS=1.000, median log1p shift=-2.226, source-fitted external median z=-4.621.
16: - `hsa-miR-320c`: KS=1.000, median log1p shift=-3.130, source-fitted external median z=-3.947.
17: - `hsa-miR-320d`: KS=0.987, median log1p shift=-2.366, source-fitted external median z=-2.939.
18: 
19: ## Frozen External Result
20: 
21: The existing standard-scaling result has ROC-AUC 0.8232 but predicts every evaluated external sample as non-cancer at the source-derived threshold: sensitivity 0%, specificity 100%, balanced accuracy 0.5. The source-fitted quantile result has ROC-AUC 0.6893 and the same threshold failure.
22: 
23: ## Decision
24: 
25: GSE106817 remains an untouched external stress test and platform-shift study. It is not added to training, and normalization alone is not accepted as a fix. A valid next experiment requires prespecified assay harmonization, a positive-control operating point defined without target labels, overlap auditing, and replication on another independent serum cohort.
