# Research sources — finalized static review

All eight current research Python implementations were substantively read in full (223,229 bytes; 3,756 lines), independently of earlier scanners. Both research READMEs and both JSON manifests were read in full. Originals were not imported, executed, fitted, searched, downloaded, modified, or deleted. CSV row counting is structural evidence, not renewed performance verification. COVERAGE records hashes and exact read ranges; evidence.py is a reusable pure static capability.

## Findings and evidentiary limits

Citations below are relative to research/; function ranges are inclusive.

1. **Specimen and units are not interchangeable.** cohort_expansion/audit_2022_gockley_workbook.py:make_report:400–524 identifies Gockley serum sequencing, caption-described log10 values, versus GSE94533 TPM/log1p; raw cells alone do not establish normalization. audit_2024_adnexal_mass_workbook.py:write_feature_maps:475–552 treats FirePlex headers as MFI, with transformation unknown. audit_cross_platform_replication.py:write_reports:323–464 distinguishes Danish plasma TaqMan RT-qPCR from serum; Janus is prediagnostic serum sequencing. audit_gse211692.py:write_report:381–506 describes signed internally normalized 3D-Gene array intensities, not TPM. Clamping signed intensities then log1p is not a validated bridge. PDF pp4–9,20,23 should retain explicit assay/specimen qualifications.

2. **Historical split selection and architecture bias.** audit_2022_gockley_published_reproduction.py:main:239–351 checks 165/55/55 workbook splits and describes >100,000 networks retained on Test assignment. Test is architecture/model-selection data, not unbiased final evaluation; Validation is internal same-cohort holdout conditional on no consultation. This is Gockley 275-subject evidence, NOT recovery of the older eLife 179-subject 135/44 split (PDF pp4,18). XML has no row-level training lineage. All-cohort metrics include fitted/selection rows; do not advertise as external validation.

3. **Scores, not probabilities; identity is conditional.** audit_2022_gockley_workbook.py:parse_pmml_model:167–237 and predict_pmml:256–287 decode weights/input scale and use maximum class output; signed tanh margin is not probability. Parser ignores layer normalization and only supports identity/tanh/logistic/rectifier: it parses animal networks but cannot faithfully replay their softmax/exponential semantics; main replays only human candidate. audit_2022_gockley_score_semantics.py:main:85–348 explicitly separates affine/sigmoid/posthoc softmax diagnostics from supported outputs. Claimed 14–8–2/128 weights/10 biases and human target/caption identify a supplied candidate, not demonstrably the selected final winner. Reported malignant/margin validation AUC .8867 versus publication .87 and argmax 38/2/5/10 versus 73%/91% remain discrepancies. 91% cannot be a standard integer specificity with 40 controls. Do not choose inverse benign AUC .8667 merely because it rounds to .87, or claim probability calibration from transformations. PDF pp15–18,23.

4. **Endpoint exclusions are material.** audit_2022_gockley_workbook.py:endpoint_masks:290–311 uses Cancer Early with separate stage for strict I/II; excludes IIIA rather than treating as control. Published-style includes 75 I–IIIA2 cases; strict includes 72. Benign-only and benign+healthy endpoints differ. audit_2024_adnexal_mass_workbook.py:write_reconstructions:345–416 and write_compatibility:555–646 pool diagnosis-0 controls because benign/healthy subtype is not encoded. Grouped stages cannot support Stage-I-only claims. audit_gse211692.py:category_for:231–244/make_label_tables:247–301 distinguish exact ovarian cancer, benign ovary, and no cancer; other cancers/diseases excluded. No explicit borderline label is not proof all borderline donors were excluded. GSE94533 replication excludes borderline and later cancer using saved diagnosis/stage fields (audit_cross_platform_replication.py:write_historical_replication:192–265). PDF pp5–8,15–17,20 require endpoint-specific labels, not generic cancer detection.

5. **Counts asserted versus saved evidence.** Available CSVs have 275 Gockley reconstruction and prediction rows, 678 FirePlex reconstruction rows, 180 panel inventory rows; these are saved derived rows, not reverified raw clinical validity. Gockley split table has four rows, metric tables 8 and 16; transformations eight. FirePlex stage table has 32 rows (categories/splits, NOT patients). Source states histology 145 worksheet rows/141 IDs: three exact repeats, one conflicting stage, 56 unambiguous I/II +84 III/IV +1 conflict +145 cancer IDs absent. Thus raw 59/86 stage totals are not 145 unambiguous people. FirePlex 468/100/110 split assertions are not all guarded as invariants in main. Source linkage compares ordered main-sheet IDs/labels then validates one-to-one merge; histology join does not assert all histology IDs belong to cancer before report claims that they do. See workbook main:837–989. Parsed workbook availability does not establish clinical validation.

6. **Mapping and deduplication.** Exact mature-arm safeguards correctly reject 32-5p for 32-3p and 200a/c for 200b (Gockley build_feature_map:358–387). FirePlex 0/5 current, 8/14 historical, 9/10 publication exact are reported; 335-5p_0_-2 and 103a versus 103 require assay annotation. GSE211692 legacy 203a is not silently equated with either arm (feature_map:304–335). Case/header normalization dictionaries can silently overwrite colliding names; should assert unique normalized keys. Cross-platform source deduplication occurs BEFORE filtering dataset (write_historical_replication:192–265), risking dropping a GSE94533 row if another dataset shares its ID. **Executable defect:** write_pelvic_mass_map:268–320 references PELVIС_ASSAYS with Cyrillic С, whereas the defined constant is ASCII PELVIC_ASSAYS; NameError prevents subsequent report generation. Saved outputs cannot certify current implementation executed successfully.

7. **Independence and reused accessions.** GSE106817/GSE113486/GSE211692 reuse GPL21263 and multiple publications may reuse donors; distinct GSE/GSM/title labels alone do not prove donor independence. audit_gse211692.py:make_overlap_table:342–378 hardcodes zero overlaps for GSE106817/GSE113486, with placeholder sets rather than reading those rosters. Its report falsely implies direct official roster comparison performed by this implementation. Duplicate normalize_id at 338–339 supersedes numeric .0 handling at 143–149. Zero IDs across namespaces is insufficient; exact duplicate expression vectors do not rule out donor repeats. The processed GSE211692 matrix is absent from current raw directory, while SOFT exists; saved tables (19 disease-label rows, seven stage rows, five overlap rows) are aggregates, not 16,190 linked expression records. Source asserts 400 ovarian/28 benign/168 I–II and 5,643 no-cancer; a specific 200-control roster is not recoverable. PDF pp4,8–9,19 must not elevate assumed independence.

8. **Transport report overreach and target adaptation.** transportability_analysis/run_transportability_analysis.py:summarize_experiments:29–50 filters ONLY test_dataset, then make_report:96–159 picks maximum target ROC-AUC and minimum target sensitivity. It does not restrict training to GSE94533 before claiming source-to-target results; potential target-trained results can be mislabeled. Picking a best normalization using target labels is descriptive posthoc selection, not independent frozen validation. Within-dataset standard/quantile are target-distribution adaptation even without labels. save_threshold_plot:66–93 calls every summary point frozen source. The script reads only results JSON and distribution CSV, never reads/validates production manifest or platform-shift JSON although manifest lists both as source artifacts. It cannot establish platform shift as the primary causal failure or rule out endpoint/model/selection defects. Claims 'no normalization alone reliably fixes' exceed this summary's evidence. PDF pp6–7,17,23 similarly should say consistent with shift, not prove biology preserved or causality.

9. **Report-generation truthfulness/staleness.** cohort_expansion/README.md and raw README still say workbook absent; manifest says present but retains reason claiming no raw table. audit_2024_adnexal_mass.py:main:196–228 overwrites that same manifest with obsolete absence claims if run; build_report:112–193 always asserts no supplement independently of detected files. Workbook report generators mix dynamic counts with hardcoded 678, stage counts, 0/5, exact reproduction, and no-missing statements without equivalent guards. Gockley make_report claims repeated metadata exactly duplicate but does not compare them. GSE report claims gzip integrity/platform/publication inspections not performed by main. Cross-platform report strings claim external GEO/SRA/Figshare/Zenodo searches not implemented here; historical provenance may exist elsewhere, but current execution would not substantiate them. Its fixed claim only one stable member and specific directions are not enforced by dynamic result checks. No output should attest activities solely because templated prose says so.

## Disposition and gaps

No clinical validation conclusion is justified here. Preserved usable evidence: static implementation review, saved table dimensions, declared endpoint/mapping rules, frozen-score semantics limitations, and source-compatibility stop gates. Unresolved: raw-to-derived lineage and workbook correctness independently of generators; exact selected human network identity; published probability conversion/operating denominator; donor-level independence across reused datasets; GSE211692 processed matrix and original 200-control roster; raw Danish/Janus access and retained subjects; target-transform lineage/selection policy; analytical assay bridge and prospective validation. PDF requested pages were read from local extracted text, not rendered visual inspection. No optional new searches or reruns were performed.
