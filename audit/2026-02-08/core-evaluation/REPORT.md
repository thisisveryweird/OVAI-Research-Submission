## Confirmed code findings

### Full-frame learned filters: outer AND inner boundary violations
- `scripts/evaluate_gse94533_diagnostic_model.py:65`: `frame[column].notna().any() and frame[column].nunique(dropna=True) > 1`, before either split. Historical layer only tests column presence, so it may retain all-missing/constant features excluded from full layer. Only filtered features receive log1p; historical constants therefore need not share the same transform. Transformation log1p itself is deterministic, not fitted leakage.
- `scripts/evaluate_methylbert_methylation.py:46`: same availability/variation predicate on **entire supplement before endpoint subsets**, allowing excluded phenotypes as well as outer/inner validation rows to influence availability.
- `scripts/freeze_methylbert_pipeline.py:40–41`: same predicate on full endpoint subset before five-fold tuning; acceptable final-training schema learning is not acceptable validation-fold learning.
- `scripts/train_mirna_baseline.py:133`, `294`, `298`: numeric candidate nunique>2, missing fraction≤.50, nunique≥3 all learned before holdout. Sheet selection also maximizes full-sheet numeric candidate count. Numeric features can include other outcome/stage columns: ID-name heuristics are not an assay whitelist.
- `scripts/train_tcga_ov_stage_model.py:131–132`: observed fraction≥.80 and nunique>1 on full usable-stage cohort before nested CV (and before numeric coercion). Its docstring's all-selection-inside-fold claim is too broad.
These are established unsupervised/transductive leaks, **not demonstrated numerical inflation**. Fitting a replacement availability transformer only on outer training would still leak inner validation into tuning; it belongs inside the searched pipeline. Other main imputation/scaling/ANOVA fits are inside training splits.

### Calibration, selection and grouping
- `scripts/evaluate_gse94533_enhancements.py:124` and `scripts/run_reproducible_baseline.py:124,133`: CalibratedClassifierCV wraps **only LinearSVC**, downstream of already-fitted preprocessing. Its internal calibration-validation rows influence imputation/scaling, and in reproducible also supervised ANOVA. Outer test rows remain excluded; this is an internal calibration boundary defect, not outer test fitting. Whole raw-input pipeline should be inside calibration wrapper. Stacking clones whole base pipelines at stack CV boundaries, but each SVM still has this nested defect.
- Selector k grids use raw feature count, not post-imputation width; defaults can drop training-all-missing columns. Diagnostic/enhancements/methylation/TCGA may offer k exceeding a fold's resulting width. Exact behavior (warning/select-all vs failed fit) is sklearn-version-dependent; no version execution claim made. Freeze hardcodes25,50,100,250,493,all without checking count. Reproducible hardcodes5,14,all though its unused local k_values suggests bounds. Indicators change width as well.
- `scripts/train_mirna_baseline.py:375`: original columns indexed by selector mask after imputer(add_indicator=True): generated indicators/drop-empty columns make names/mask inconsistent, potentially raising or mislabeling. `scripts/evaluate_gse94533_enhancements.py:219`: lasso fitted on X_base19 but zipped against feature_names23 including four intervening ratios: labels after first16 are wrong even with no missing columns, and dropped columns worsen it. This invalidates named stability, not coefficients themselves.
- Spreadsheet `patient_id_column` at302 and `calibrate_threshold` at348 have no definitions/imports anywhere in fully read file: main cannot complete as written. Comment promises cohort metadata but concatenation adds none. Intended GroupShuffleSplit has no class stratification; fewer than10 groups disables grouping even if repeats exist. fillna(Index) can also be incompatible with pandas fillna argument expectations. No actual grouping is established.
- Diagnostic verifies one-to-one sample joins, not unique biological patients. Enhancements has no duplicate assertion; reproducible checks unique normalized sample IDs, not biological patient identity. All use row StratifiedKFold. TCGA deduplicates patients first, which prevents barcode-prefix repeats but chooses first aliquot by upstream order, not documented specimen-quality/type rules. Cross-study overlap is not checked in these scripts.

### Thresholds, saved OOF and uncertainty
- Spreadsheet threshold is explicitly tuned on y_test,p (`train_mirna_baseline.py:348`); threshold-dependent test metrics exploratory/optimistic, not unbiased holdout. This is threshold selection, not fitted probability calibration.
- Enhancements (`183–205`) and reproducible (`355–363`) threshold OOF probabilities reuse hyperparameters selected on all outer-training labels, including each threshold-CV validation fold. This is selection leakage within threshold fitting, not direct outer-test use. Additional nested search or dedicated calibration split needed for strict independent threshold-training estimates.
- Enhancements `230–241`: initial tuned metrics/confusion use median threshold; four headline classification metrics overwritten with fold-specific predictions **but confusion matrix remains median-threshold matrix**, yielding internally inconsistent JSON. Export saves .5 predictions only, not tuned or specificity-target predictions/fold IDs. Specificity95 target is training-only, and fallback chooses maximum sensitivity then specificity when target infeasible, not maximum attainable specificity.
- Reproducible `376–380`: aggregate metrics/CI use median of row-assigned fold thresholds while saved prediction uses fold-specific thresholds; median is weighted by fold size. Each row's reported classification can thus disagree with comparison metrics; aggregate threshold is learned across overlapping training folds containing that row's label, so it is not a clean nested classification policy. Ranking and Brier use untouched outer OOF probabilities.
- Reproducible bootstrap300 resamples fixed row OOF predictions, skips one-class samples; percentile95 intervals condition on fitted models/selected thresholds, do not refit, capture split/model/selection uncertainty, or respect unverified patient clusters. Label as conditional OOF row-bootstrap intervals, not individual prediction confidence. Other eight sources have no inferential CIs; fold point metrics are not uncertainty intervals.
- Diagnostic saves probabilities+fixed decisions and fold summaries, but not row-fold IDs, best parameters or selected features. Methylation retains OOF decision scores only in memory (misnamed probabilities), then saves aggregates. Frozen gene script only prints; cannot independently reconcile run/OOF/threshold from a committed output. Reproducible saves row fold/probability/threshold and per-model params JSON, calibration bins, versions Python/numpy/pandas but not sklearn/xgboost or input/source hashes.
- Diagnostic and TCGA `majority_class_accuracy` are y.mean() (positive fraction), not max(y.mean(),1-y.mean()); only equal majority baseline when positives dominate.

Genuine design choices: (1) nested discovery measures a learning procedure; untouched validation measures a predeclared fixed assay—neither substitutes for the other. (2) dedicated calibration/threshold holdout trades small-cohort sample efficiency for independence; fully nested cross-fitting uses more compute and must refit tuning at each boundary. (3) fixed .5 or score0 is reproducible but not clinically optimal; predeclared sensitivity/specificity policies require independent operating-point validation and infeasibility reporting. (4) patient-dedup with deterministic specimen rules vs group-aware evaluation retaining repeats depends on intended unit/visit; arbitrary first aliquot is not a principled alternative. (5) probability calibration cannot cure unsupported target prevalence or cross-platform measurement shifts; prospective harmonized assay validation is distinct from fitting another calibrator.
