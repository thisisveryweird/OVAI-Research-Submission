## Disjointness, missingness and metrics
Diagnostic/enhancement/methylation evaluators use row StratifiedKFold, not groups, with no patient overlap assertion (`diagnostic main:79–89`, `enhancements main:97–107`, `methylation evaluate:59–64`). One-to-one diagnostic joins validate keys, not person independence. TCGA barcode dedup is the strongest explicit patient treatment in this scope. All evaluators lack explicit minimum per-class split-count guards; one-class AUC or confusion_matrix.ravel can fail. Diagnostic historical layer tests column presence, not its global eligibility: all-missing historical columns can survive. Fixed log1p in diagnostic lacks negative/infinite validation; reproducible clips negatives but does not explicitly reject infinities. Median/KNN imputers may drop all-empty fold columns; raw-width k bounds are insufficient, and freeze's fixed k grid is entirely unbounded. There is no universally safe all-missing path demonstrated.

Diagnostic `main:106–119`, enhancements `main:233–248`, methylation `evaluate:86–96`, TCGA `main:206–217` compute pooled OOF metrics, not fold means; fold metrics are also stored separately. Pooled AUC compares scores across different fitted folds and is not interchangeable with mean fold AUC. Reproducible summaries use pooled median-threshold rule; saved predictions use per-fold rules. Enhancements tuned confusion remains inconsistent as above. No metric recomputation was possible locally.

Persisted diagnostic and enhancement prediction CSVs contain IDs, labels, probabilities and fixed-.5 decisions only (`diagnostic:81,120–121`; `enhancements:258–264`), not fold IDs, tuned decisions/threshold per row or fit provenance. Reproducible CSV includes model/patient/fold/label/probability/threshold/decision, parameters per fold in comparison and seed/version/path metadata (`392–460`), but lacks input hashes, code revision, sklearn/xgboost versions and group-overlap evidence. Methylation evaluator persists aggregate JSON only; freeze metadata has feature names/params/training-only flag (`70–77`) without hashes/versions/split provenance. No OOF threshold can be independently linked to frozen methylation artifact from these files.
