## Findings with precise evidence
Line references are in `scripts/`; module scope is explicit where no function exists.

1. **The non-final Stage-I script cannot establish its named result.** `test_frozen_signature_stage1_gse12172.py` module 243–259 locates diagnosis but never constructs `labels`; 318–330 references that undefined variable. `normalize_stage` 271–305 returns IA/IB/IC and II/III substages, while 322–325 tests only `['I']`, which that function never returns. Even supplying labels would select no malignant cases. The assertions at 365–380 expect 30 LMP and 16 cancers; they are not measurements. The `_final.py` version constructs labels at 429–440, normalizes stage in `normalize_stage` starting at 488, selects exact IA/IB/IC at 543–553 and asserts 30/16 at 610–624. It trusts characteristic row index 3 (482), not a schema/version check. Source paths differ: relative `data` here versus home-directory paths in the other transfer family.

2. **Generic malignant validation is not Stage-I-only validation.** `test_gse8841_signature_on_gse12172.py` module 425–469 classifies generic LMP/malignant with no stage restriction; `_clean.py` 280–344 does the same; `_final.py` 279–304 selects generic malignant and asserts only total 90. Its comment `Probability of malignant/stage-I cancer` at 427 does not establish target Stage-I identity. The source-trained positive class is `stage_I_cancer` (original 374–377; clean 253–255; final 238–240), but target positives are all malignant. Do not transplant a discovery class name onto target cases. The explicit Stage-I final script is a different endpoint (30+16 expected rather than 30+60). No requested script independently proves an I/II serum subgroup is Stage I; the PDF's GSE94533 I/II issue remains a separate metadata limitation, not resolved by these tissue scripts.

3. **Frozen gene names are not necessarily frozen assay/model transfer.** GPL5689/GPL570 readers match exact uppercased gene-symbol strings, collapsing multiple probes by median (original 319–365, 517–568; clean 222–244, 346–381). Multi-symbol annotations are not disambiguated. Original and clean require every requested gene; final 324–367 discards unmeasurable target genes and accepts >=10, then retrains on the reduced source matrix (381–425). IFI30 removal is explicit in `test_frozen_signature_gse9899.py` 23–25 and GSE12172 final 515–517, not a data-verified absence here. Final Stage-I uses exactly 12 fixed names and fails on absent probes (656–679). Source-only scaling and LR fitting are clear (Stage-I final 710–730; generic final 401–425); labels are used for target evaluation, not fitting there. Prespecification time, gene-discovery provenance and prior human target inspection cannot be proven by comments saying frozen.

4. **GSE9899 is a target-normalized exploratory score, not the same source-frozen classifier.** `test_frozen_signature_gse9899.py` module 258–268 retains whatever genes are available, z-scores across the target cohort, then averages. `auc_for` 286–302 evaluates LMP=1 (284), opposite the GSE12172 malignant=1 convention. It evaluates all malignant and IA/IB/IC subsets (308–327); the 'non-Stage-I' complement includes unknown stage values. `gse9899_gene_diagnostics.py` 146–151 likewise computes target-global statistics; 183–199 and 240–252 chooses/reports best direction from target labels. Such best-direction AUC is exploratory label-informed orientation, not an untouched transfer estimate. Positive rescaling preserves each single-gene rank but target-specific multigene relative weights are not source frozen. Its combined score 260–265 is another target-standardized mean, not LR probabilities. `diagnose_gse9899_signature.py` 39–42 inspects the existing Stage-I subset; it does not establish patient independence or recreate gene values.

5. **GSE9899 identity is title/key matching only.** `map_gse9899.py` module 10–26 treats `!Sample_title` as AOCSID and left-merges clinical annotations without one-to-one validation. Its 'Clinical without expression' count at 36 uses `right_only`, impossible in a left merge; zero does not prove completeness. Expression readers in the GSE9899 test (59–109) and diagnostics (37–77) assign titles positionally instead of verifying the actual matrix accession header. Clinical audit 108 opens `.gz` with ordinary `open`, catches errors (129–130), potentially producing no valid accession audit. Exact string overlap (150–167) alone cannot establish distinct patients across studies. Duplicate titles, repeated patients/specimens and title-to-accession identity require source tables.

6. **TCGA is tumor molecular pairing / staging / prognosis, never diagnosis validation.** `build_tcga_304_paired_molecular_dataset.py` module 90–105 intersects exact sample keys; 232–253 validates one-to-one merges, but never canonicalizes patient barcodes or tests aliquot/repeated-patient grouping. Approximate 304 is only a warning, not an invariant. `extract_tcga_172mirna_audit.py` 39–46 asserts 172 matched mapping rows; 48–59 dictionary mapping can collapse duplicate MIMAT IDs, with no uniqueness/arm-version check. It requires exact Xena field membership (83–99), renames values to historical names (141–147) and joins sample strings (214–219). Exact MIMAT correspondence still needs original mature-arm/version/assay evidence. RNA/miRNA/age pairing does not provide serum linked measurements or controls.

7. **Global learned preparation and inner-fold leakage.** `build_tcga_clean_multimodal_dataset.py` module 59–71 selects miRNAs by full-cohort missingness <=20%; 142–155 imputes retained columns with full-cohort medians despite warning at 137–139. Reusing this prepared matrix in heldout CV contaminates preprocessing; actual lineage into the later 223-protein dataset is unproven here. `build_tcga_multimodal_stage_model.py` `decode_stage` 110–125 decodes Xena codes; `stage_class` 148–175 explicitly codes III/IV=1, I/II=0, unknown excluded (223–227). GridSearchCV wraps scaler and ANOVA selection in a pipeline and fits only outer training rows (405–467), containing those learned statistics within inner folds. It rejects missing values, so upstream global imputation cannot be undone. Dynamic feature lists mean model name `age_plus_151mirna` (264) is not proof of 151 features. Reported N=223 and exclusion '9 overlapping patients' (599–606) are source strings, not verified counts.

8. **Survival is not staging or detection.** `build_tcga_survival_ablation.py` module 57–84 obtains OS/OS.time and excludes missing/nonpositive durations; OS is cast to int but binary coding is not asserted. Cox fits correctly use `OS.time` as duration and `OS` as event (264–283, 306–321). Unused `durations` at 205 mistakenly uses OS, but does not change those fits. Outer scaler is fit at 223–229 before inner splits at 251–262, so inner validation sees scaling statistics from its own heldout rows. Outer test scaling remains source-fold-only. Pooled OOF C-index (352–356) compares hazards from independently fitted fold models; cross-fold hazard scales are not necessarily comparable. Fold C-indices and a defensible aggregation should be distinguished. No external survival validation exists in this script.

9. **Target development must not be relabeled external validation.** `test_balanced_cancer_borderline.py` 23–42 takes GSE106817 target rows, complete-cases age+miRNAs, cancer=1; 58–85 repeatedly downsamples cancer to borderline count (20 repeats). Pipeline fitting at 100–129 uses target-fold labels and data; this is target-cohort development/stability, explicitly disclaimed as external validation at 176–177. Repeats share borderline cases and overlapping cancer samples, not 20 independent validations.

10. **GSE106817 label policies differ.** `extract_gse106817_validation_cohort.py` `classify` 97–113 selects title prefixes and includes cancer/borderline/benign/control; 408–410 assigns cancer=1 and all others=0. Repeated characteristics rows overwrite in metadata dict (68–77), so age parsing 144–171 examines only the final row. No stage assertion exists. `audit_gse106817.py` 61–63 likewise overwrites repeated fields; nonexclusive regex counts 107–126 include ovarian/non-cancer matches in generic 'Other solid cancer' regex, so these counts cannot be summed. `audit_gse106817_platform_shift.py` `load_external` 75–95 excludes borderline from evaluated controls, unlike extraction. It aliases miR-203a to miR-203a-3p (65–66) and uses last-value dictionaries (64), requiring mapping provenance. `main` 101–110 source-fits scaler/quantile transforms; target summaries/KS at 113–127 are descriptive, not fitted label-based harmonization. Hardcoded performance prose at 165 is not a newly computed model evaluation. No scale correction proves assay equivalence or independence.

11. **Feature presence checks are not exact biological compatibility.** `diagnose_external_feature_firewall.py` `normalize` 54–55 strips punctuation; `audit_one` 109–118 uses substring containment across union of all platform and expression identifiers. Annotation-only matches can satisfy the signature while expression tables contain none of its mapped probes; substring hits can be false positives. 'Exact signature' output overstates that test. Mature 3p/5p arms are retained numerically in normalization, but substring matching and absent probe-to-row joins still require manual validation. `audit_methylbert_external_targets.py` `main` 21–41 makes live requests if run (not run); regex ovarian OR methyl (34) cannot establish valid ovarian methylation data and conflicts with hardcoded exclusion reason (35). Nonempty exact intersection (39–40) alone does not establish all required features, assay alignment or tissue/blood equivalence. No frozen prediction is performed for HRA011451 (44–45).
